# Customer Churn Prediction Using Machine Learning

## Project Description

Customer Churn Prediction is a Machine Learning-based web application developed to identify customers who are likely to discontinue a telecom service. The system analyzes customer demographic information, subscription details, service usage patterns, and billing history to predict churn behavior and support proactive customer retention strategies.

The project utilizes a Random Forest Classifier trained on the Telco Customer Churn dataset. Data preprocessing techniques such as handling missing values, label encoding, and feature scaling are applied to improve model performance. The trained model is integrated with a Flask-based web application, enabling users to input customer information and receive real-time predictions.

## Key Features

* Predicts whether a customer is likely to churn or remain with the service.
* Displays churn probability percentage.
* Categorizes customers into Low, Medium, or High Risk groups.
* Provides retention recommendations based on predicted risk levels.
* Interactive and user-friendly web interface developed using Flask and Bootstrap.
* Efficient data preprocessing and model deployment using Python.

## Project Outcome

The Random Forest model achieved an accuracy of approximately 78%, effectively identifying customers with a high probability of churn. The system provides valuable insights such as churn probability, risk assessment, and retention suggestions, helping organizations improve customer retention and reduce revenue loss.
